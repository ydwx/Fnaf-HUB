## 📖 عن الموقع / About

### 🇸🇦 العربية
موقع متواضع يجمع ألعاب سلسلة فناف في مكان واحد، مع تصميم بسيط وأنيق يدعم الوضع المظلم واللغة العربية والإنجليزية. تم إنشاء هذا الموقع لتسهيل الوصول إلى الألعاب والمعلومات الخاصة بها.

### 🇬🇧 English
A humble website that gathers FNAF games in one place, with a simple and elegant design that supports dark mode and both Arabic and English languages. This site was created to make accessing games and their information easier.
